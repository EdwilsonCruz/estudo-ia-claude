## Como Usar o Claude Code neste Projeto

```bash
# Navegar até o projeto
cd /c/caminho/para/estudo-ia-claude

# Iniciar o Claude Code
claude

# Comandos úteis dentro do agente
/help        # lista todos os comandos disponíveis
/compact     # compacta o contexto quando a sessão ficar longa
/clear       # limpa o contexto mantendo os arquivos
/bug         # reporta um problema diretamente para a Anthropic
```
